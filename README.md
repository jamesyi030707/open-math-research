# 数学研究手记
*Mathematical Research Notes*

关于构造、算法与可计算性的研究笔记：一个结论如何得到证书，一个看似有效的改进为何受阻，以及这些结果怎样约束下一步。

记录来自与 Claude 的数学讨论、实验代码及分开编写的核验实现。专题页中的引文摘自真实存档；研究评注是本次整理，结果均注明适用的模型与范围。

## 从这里读起

### [纠错码：让模型成为证明的输入](notes/codes-proof-input.md)

完整距离条件已转成可逐项审查的整数约束，奇偶辅助位从五个压缩到三个。阳性对照有明确见证；完整模型仍在等待可独立检查的证明。

### [纠错码：模型说不可行，证明还缺什么？](notes/codes-covering.md)

共同变量模型已完成有界求解，返回不可行但没有证明证书。独立审查确认模型与降维正确；下一步转向可验证的否定证据。

### [纠错码：二十五个可行分布，还不是一个码](notes/codes-coset.md)

换用已知的扩展 BCH 母码后，精确必要条件留下二十五个分布。它们并非构造；真正的下一步是让八个 Walsh 谱同时来自一个共同函数。

### [纠错码：从六十九万次核查，到一个谱证书](notes/codes-spectral.md)

改变全部坐标，也未必能越过旧码的结构。一个只需核查 2,047 个字符和的证书，排除了基准码的整个低秩改动家族，并省掉下一层约五千万个子空间的枚举。此前的四列障碍保留在专题历史中。

### [Collatz：从逆树到剪枝，为什么停在这里](notes/collatz.md)

J=92 的逆向节点从约 10.96 亿降到 2,200 万，同轮计时仍慢于正向基线。这个实验留下了可核查的有限结果，也给出一个停止理由：更少节点尚未改变整体成本。

### [HoTT：逐项可判定，能否回答整个无限问题？](notes/hott.md)

早期探索围绕局部判定与全局证书展开。把查询算法、条件性的纸笔论证和类型论中的形式化陈述分开，问题才有明确的下一步。
