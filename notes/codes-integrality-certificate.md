# 一千多个整除条件，压成六条同余

[上一则](codes-split-affine-model.md)给出了固定残余、投影核维数1分支的1064个分割对偶系数。今天不再扩展数表，而是完成此前留下的精确约简：**对所有整数七元组，全部1064个系数为整数，当且仅当六条同余成立。** 两个方向都有可逐项检查的线性组合证书。

这只压缩整除条件。非负性、计数范围和线性码可实现性没有因此消失；没有构造新码，也没有排除整个分支。2026年11月3日直接读取 Grassl [64,11] 条目，页面仍显示26–27；这是该表的当前显示，不是穷尽文献的新颖性认证。

## 六条条件

变量仍为 \(x=(p,q,y_{10},y_{14},z_8,z_{12},z_{16})\)。精确条件是

\[
\begin{aligned}
p+q+2y_{10}+y_{14}+3z_8+2z_{12}+z_{16}&\equiv12&&\pmod{64},\\
2q+2y_{10}+y_{14}&\equiv8&&\pmod{16},\\
q+y_{10}-z_{12}-z_{16}&\equiv6&&\pmod8,\\
q+2z_8+2z_{16}&\equiv0&&\pmod4,\\
z_{12}+z_{16}&\equiv0&&\pmod2,\\
z_8+z_{16}&\equiv0&&\pmod2.
\end{aligned}
\]

最后一条成立时，第四条可写为 \(q\equiv0\pmod4\)。三个 \(z\) 变量具有相同奇偶性。这里不声称六条已是某种唯一或最小表示。

## 为什么是等价，而不只是筛选

原分子矩阵的每项（包括常数列）都能被16整除。因此模1024整除等价于除以16后的模64整除。记得到的1064×8矩阵为 \(A\)，作用在 \((x,1)\) 上。

证书给出六行矩阵 \(B\) 和两个线性组合矩阵 \(L,R\)，满足
\[
B=LA\pmod{64},\qquad A=RB\pmod{64}.
\]
第一式说明原条件蕴含六行条件，第二式说明六行条件蕴含全部原条件。常数列参与每一项核查，避免只证明齐次部分等价。再把各行与模数同时除以公因子，得到上面的六条同余；没有把偶数错误地当成模64可逆元。

生成过程使用精确模环行消元，而非实际计算巨大 Smith 变换矩阵。证书本身不依赖生成算法是否可信：两份分开编写的检查器直接核查双向恒等式。前向证书只使用源表的六个位置 \((1,0),(1,1),(1,2),(2,0),(2,1),(3,0)\)，反向证书覆盖全部1064行。

## 关键交流：模同余不等于整数范围

11月2日的讨论提出 Smith 标准形处理非单位因子和零行的正确框架；11月3日继续检查变换后的计数范围。Claude明确说：

> “Bounds l ≤ x ≤ u become l ≤ Vy ≤ u.”

它给出的二维例子是 \(x=(1,9)\)，对应 \(y=(19,9)\)。把 \(y\) 草率改成模16的标准代表 \((3,9)\)，会映回 \(x'=(-15,9)\)，丢掉原来合法的非负整数解。独立小例核验确认这点；应保留整格平移并运输全部不等式，而不能只测试一个代表。

## 研究评注与下一步

旧形式点 \((0,0,140,16,8,6,64)\) 满足全部六条条件，却仍有八个负系数，包括 \(J^\perp_{1,2}=-16\)。所以这个结果是精确模型压缩，不是可行性证明。原计数域和全部非负性条件仍须保留。

本次确定性计算每项都在一分钟预算内；没有枚举计数域，也没有搜索生成矩阵。后续不再整理同一整除表：若继续该分支，先用六条同余参数化整数格，并证明每个原边界和非负性不等式被正确运输；之后仅在另定预算及可独立核验的证书方案下检查可行性。若仍只是改写而无新的可计算对象，应转向不同结构问题，不能把无证书搜索失败称作不存在。
