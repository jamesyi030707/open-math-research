# 五个残余列，给出比分布更强的限制

[昨天的消息子空间](codes-subspace-obstruction.md)把固定残余、核维数1分支的参数限制为q∈{16,20,24,28}。今天先检查这四种可能：每种都仍有通过全部1075条旧条件的整数分布。继续求解同一个计数模型，不能得到分支排除。

新的信息来自列的位置关系。固定残余矩阵B中，恰有五列能够与左块A的列相同；这五列又全部在昨天的五维消息子空间S上取零。于是，原来分开非负的两个对偶系数，必须共同服从一个列数上限。

## 两类列，分享同一个上限

沿用[七整数参数](codes-integer-lattice.md)(a,b,c,d,e,f,g)，其中q=4d。S的31个非零消息在左块的重量为12或16。由一阶矩，A的27列中，恰有d−4列在S上恒为零。

令Z为A的全零列数，M为A与B相同的列对数。实际二元码的分割对偶系数有直接的列解释：

- T(1,0)=Z=a−6；
- T(1,1)=M=b−3a+4。

第二式成立，是因为一个各取左右一坐标的重量2向量属于对偶码，当且仅当这两个生成矩阵列相同。

B的37列互不相同且都非零。核消息h=1008满足hA=0，因此A能匹配的B列只能是十位标签{1,4,7,13,15}；逐列核验表明，它们均在S上为零。全零A列与这些匹配列互不重叠，又都占用那d−4个位置，故

Z+M≤d−4，亦即 **2a+d−b−2≥0**。

新不等式的余量，正是在S上为零、但既非全零也不等于任何B列的A列数。与旧条件T(1,0),T(1,1)≥0合用，它还蕴含d≥4，所以包含昨天的q≥16下界。

## 一个通过旧条件、却多出五次匹配的点

取整数参数(6,19,10,4,−31,−33,66)，对应七计数

(p,q,y10,y14,z8,z12,z16)=(26,16,140,0,0,4,66)。

它通过11条计数边界和全部1064个分割变换系数的非负整数检查，也满足q≥16。然而d=4要求没有任何A列在S上为零，而T(1,1)=5要求五个这样的列位置。新余量为−5，矛盾与其余消息如何分配标签无关。

因此，这条列关联限制确实强于旧形式模型加q≥16，排除了这个指定形式点的所有标签实现。它仍未排除任何一个剩余q值：每个q都有通过新旧全部条件的形式见证。形式可行性与真实矩阵可实现性继续分开。

## 对话中的另一条结构信息

本日真实交流先研究S限制码的重复列。二阶矩给出重复列对数：q=16,20,24,28时分别为6,5,3,0。因此q=28时，24个有效列必须互异。

Claude在实际回复中给出了精确分类：

> “So the restricted code is the simplex [31,5,16] code with the seven nonzero column vectors of a 3-dimensional subspace removed.”

证明也很短：在31个非零五位列中，缺失的七列对各消息的重量只能为0或4，恰有三个非零消息取0。连同零消息，核大小为4，所以七列张成三维空间；它们恰是该空间全部非零向量。分开编写的证明与程序核验了这一限制码及相关余类矩恒等式，但没有检查其与完整残余B的全部扩展兼容性。

## 核验、研究评注与下一步

初始检查器与另写的坐标/多项式实现，分别核对1024个残余消息、全部1064行变换、被拒绝点及四个存活点。所有512种满足h正交的列标签也通过列计数检查。发布时重跑结果一致。

另有一个真实27列、秩9的左矩阵达到新不等式等号，并实现S上的q=16重量分布；它在完整残余提升条件上有130个消息失败。这个控制验证列论证，不是目标码。
