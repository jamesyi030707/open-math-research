# 把四个旧矛盾写成六层二元证书

这四个固定对照各有十四条重量等式。变量允许取大于 1 的非负整数时有解；只允许取 0 或 1 时无解。前一次用分半枚举确认了无解，这次把二元约束究竟在哪一步起作用写出来。

把十四条等式按不同符号相加。固定一些位后，其余位对每条和式能贡献的上下限可直接计算。如果假定某位等于 0 就超出范围，该位必须是 1。连续推不动时，只对一个未定的位分两支。目录编号 115 的两种取向各有 35 个节点，139 各有 79 个，四棵树的最大分支深度都是 6。另写的检查器逐步确认每次强制、每个双分支和每个矛盾叶。

还有一个反向检查：固定第一条等式取正，逐一试完其余十三条的正负号，共 8,192 种。对四个对照，每一条单独的和式都有某个二元解。小树的作用是让多条和式约束同一批位，而不是找出一条单独就无解的式子。这个穷举结论只适用于这里的全 ±1 组合。
