# Character-sum obstruction through codimension three for the fixed binary [64,11,26] code

Date: 2026-10-15.

## Result and scope

Let C be the code generated by the accompanying 11-by-64 matrix. A compact
character-sum certificate proves that every dimension-8 subcode of C
contains at least **3 codewords of weight 26**. Sharpness of this dimension-8
lower bound is not asserted; no rank-3 dual-space enumeration was performed.

Every dimension-9 subcode of C contains at least **36 codewords of weight 26**.
The lower bound is exact: **125** of the **698,027** dimension-9 subcodes
attain it. The largest such intersection has 87 words.

Consequently, if D is a binary linear [64,11] code with minimum distance at
least 27, then

    dim(C intersect D) <= 7.

This is a statement about overlap with this fixed code. It is not a proof of
nonexistence of a binary linear [64,11,27] code, does not improve the global
table bounds, and makes no novelty or priority claim. No column-replacement
experiment is performed here.

## Input and conventions

The matrix is copied byte-for-byte from the independently reproduced matrix
in `../../2026-10-14/independent/generator_matrix.txt`. The earlier reproduction
credits Markus Grassl's Code Tables:

https://www.codetables.de/BKLC/BKLC.php?k=11&n=64&q=2

That source construction starts from a binary cyclic [65,13,25] code, extends
it by parity, and shortens two specified coordinates. This calculation uses
only the supplied fixed matrix; it does not refetch or reassess current table
bounds. The input is mathematical data; the new programs are independently
authored and require no external code or packages.

Integer message bit i selects generator row i+1, starting with bit 0.
For integer dual vectors a and messages m, their binary dot product is the
parity of the number of set bits in `a & m`. Printed matrix columns run from
left to right. Both full-enumeration programs verify rank 11 by checking
that all 2,048 encoded messages are distinct, and both recover the complete
weight distribution:

    weight:   0   26   28   30   32   34   36   38   40
    count:    1  234  259  420  396  186  261  216   75

Write S for the 234 nonzero message vectors encoding weight-26 words.

## Why the enumeration covers every dimension-9 subcode

Since the matrix has rank 11, encoding is a vector-space isomorphism from
V = F_2^11 onto C. Thus every dimension-9 subcode corresponds to a unique
dimension-9 subspace U of V.

The standard dot product on V is nondegenerate. The annihilator

    U-perp = {a in V : a dot u = 0 for every u in U}

has dimension 2, and U is the common kernel of any basis a,b of U-perp.
Conversely, any independent a,b yield a dimension-9 common kernel. The
annihilator operation is a bijection between these subspaces.

A binary 2-dimensional space has exactly three nonzero vectors a,b,a+b.
There are (2^11 - 1)(2^11 - 2) ordered independent pairs, and each 2-space has
six ordered bases. Therefore the exact number of cases is

    (2047 * 2046) / 6 = 698027.

The first program iterates integer vectors satisfying 0 < a < b < (a XOR b).
Every 2-space appears exactly once: a and b must be the two smallest of its
three nonzero vectors, and their sum is the largest. For each a, a bitset
records which messages in S satisfy a dot m = 0. A bitwise intersection and
population count give exactly

    |S intersect ker(a) intersect ker(b)|.

All 698,027 counts are positive. Their minimum is 36, with multiplicity 125.
The complete histogram and all 125 minimizing annihilator spaces appear in
`codim2_results.json`; each space is represented by its three nonzero vectors
in increasing order.

## Compact character-sum certificate

Full enumeration is useful for the exact histogram but is unnecessary to
verify the lower bound. Define the integer character sums

    F(a) = sum over m in S of (-1)^(a dot m).

Direct calculation for all 2,047 nonzero a gives **F(a) >= -30**. Exactly
111 nonzero dual vectors attain -30. For any independent a,b, all three
vectors a,b,a+b are nonzero. Expanding the two zero-dot-product indicators
therefore gives

    |S intersect ker(a) intersect ker(b)|
      = [234 + F(a) + F(b) + F(a+b)] / 4
      >= (234 - 30 - 30 - 30) / 4 = 36.

For a=41, b=460, and a+b=485, all three character sums equal -30, proving
sharpness. Equality is possible only when all three nonzero annihilator
vectors attain -30. Among the 111 vectors, exactly 125 such complete triples
occur, which also verifies the equality multiplicity without full rank-2
enumeration.

`codim2_compact_verify.py` is a short standalone verifier of this certificate.
It needs only the matrix, does not read the claimed JSON or import the other
programs, computes dot products directly, checks all 2,047 character sums,
and inspects at most binomial(111,2)=6,105 pairs to count equality cases.
The full nonzero character histogram and the 111 minimum-character vectors
are also stored in `codim2_results.json`.

Equivalently, every hyperplane contains at least 102 messages of S, since
its intersection size is (234+F(a))/2. Three hyperplane bounds give the
codimension-two bound above.

### Stronger codimension-three consequence, without further enumeration

For any r-dimensional dual subspace A, the orthogonality identity is

    1_{m in A-perp} = 2^(-r) * sum over a in A of (-1)^(a dot m).

Indeed, when m is orthogonal to A every summand equals 1. Otherwise some
a0 in A has a0 dot m = 1, and the involution a -> a+a0 pairs opposite signs,
so the sum vanishes. Summing this identity over m in S yields

    |S intersect A-perp|
      = [234 + sum over nonzero a in A of F(a)] / 2^r
      >= [234 - 30*(2^r - 1)] / 2^r.

For r=3, this gives (234 - 7*30)/8 = **3**. Every dimension-8 subspace is
the orthogonal complement of some 3-dimensional dual subspace, so the result
covers every dimension-8 subcode. The same 2,047 scalar character checks are
sufficient. No enumeration of rank-3 kernels or assertion that the bound 3
is attainable is needed. The certified bounds are 102 for dimension 10,
36 for dimension 9, and 3 for dimension 8.

## Independent full-enumeration verification

The verifier does not import the enumerator. It encodes messages as literal
64-coordinate arrays, computes the indicator f of S, and obtains all Walsh
sums by an integer fast Walsh-Hadamard transform:

    F(a) = sum over m in S of (-1)^(a dot m).

For any independent a,b, expanding the two zero-dot-product indicators gives

    |S intersect ker(a) intersect ker(b)|
      = [234 + F(a) + F(b) + F(a+b)] / 4.

Instead of sorted triples, the verifier enumerates all unique rank-2 reduced
row-echelon matrices. For pivot columns p < q (indexed 0 through 10), the
first row has leading 1 at p, zero at q, and arbitrary entries to the right
of p outside q; the second has leading 1 at q and arbitrary entries to its
right. All entries left of each pivot are zero. The standard uniqueness of
reduced row-echelon form gives a second exhaustive, nonduplicating enumeration
of the same dual 2-spaces.

The verifier checks the full histogram, all minimizing spaces, the displayed
example, and the following double-counting identities:

    sum_U |S intersect U| = 234 * 174251 = 40774734;

    sum_U binomial(|S intersect U|,2)
      = binomial(234,2) * 43435 = 1184081535.

For the first identity, a fixed nonzero message is annihilated by a dual
2-space precisely when that space lies in its 10-dimensional orthogonal
hyperplane; there are (1023 * 1022)/6 = 174251 such spaces. For the second,
two distinct nonzero binary messages are independent, so their common
orthogonal space has dimension 9 and contains (511 * 510)/6 = 43435 dual
2-spaces. These identities are consistency checks rather than substitutes
for enumeration.

## Exact example and consequence

The first minimizing annihilator has nonzero integer vectors 41, 460, 485;
41 XOR 460 = 485. The common kernel of 41 and 460 therefore has dimension 9.
Its explicit message basis, encoded 9-by-64 generator matrix, full weight
distribution, and list of 36 weight-26 messages are included in the JSON.
This proves that the numerical lower bound 36 is sharp for this C.

If dim(C intersect D) were at least 8, the intersection would contain a
dimension-8 subcode of C. The verified character-sum result forces at least
3 weight-26 words into that subcode and hence into D, contradicting distance
at least 27. This proves the stated overlap bound of 7. The exact
dimension-9 enumeration alone gives the weaker overlap bound of 8.

Another direct consequence is that no linear extension of this C by up to
three coordinates can have distance at least 27: the appended linear
functionals have a common kernel of dimension at least 8, leaving a weight-26
word unchanged. This consequence concerns extensions of this C to lengths
at most 67, not arbitrary codes of those lengths.

## Why a seven-word constant-weight linear-subspace certificate cannot work

One might seek a 3-dimensional subcode whose seven nonzero words all have
weight 26. Such a subcode would meet every codimension-two subspace in a
nonzero vector, giving an even shorter obstruction. It cannot exist here,
or in any binary code: the sum of the seven nonzero weights would be
7 * 26 = 182. On a 3-dimensional binary subspace, each coordinate restriction
is either identically zero or is a nonzero linear functional taking value 1
on exactly four vectors. Thus the total weight must be divisible by 4, while
182 is not. This rules out that specific seven-word equal-weight linear
subspace certificate. It does not rule out nonlinear sets of witnesses,
weighted certificates, or the character-sum certificate supplied above.

## Reproduce

From this directory, with ordinary Python 3 (no install or network needed):

    python3 codim2_enumerate.py
    python3 codim2_verify.py
    python3 codim2_compact_verify.py
    sha256sum -c codim2_SHA256SUMS

The enumerator deterministically rewrites only `codim2_results.json`. Timing
is printed to stdout and is excluded from that JSON, so the data are stable.
The verifier reads the matrix and JSON without changing either. Stored logs
document the completed runs; both scripts enforce exact assertions. Do not
run Python with optimization flags that disable assertions. The computation
completed well within the requested 120 CPU-second limit.
