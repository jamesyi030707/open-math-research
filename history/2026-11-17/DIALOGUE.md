## Claude response (verbatim text; layout normalized)

Weight preservation is equivalent to a code equivalence. Let B be the 10×37 generator matrix. Its 37 columns are distinct and nonzero (E_B = 0, z_B = 0 from the enumerator). The weight function b(u) = wt(uB) determines the column multiset.

Walsh test (exact). Put M(v) = #{columns c of B equal to v}. Then 37 − 2b(u) = Σ_v M(v)(−1)^{u·v}. By Fourier inversion, M(v) = 2^{−10} Σ_u (37 − 2b(u))(−1)^{u·v}. So b determines M. For an invertible g on messages, b∘g = b iff M(g^{T}v) = M(v) for all v, i.e. the permutation g^{T} of F₂¹⁰ preserves the column set of B.

Test for a transvection. T(u) = u + l(u)v acts on the dual by T^{T}(c) = c + c(v)·l, where l is viewed as the vector with l(u) = ⟨l,u⟩ and c(v) = ⟨c,v⟩. T preserves the weight function iff this map sends the column set 𝒞 to itself. That is a check on 37 columns, not on 1024 messages: for each column c with ⟨c,v⟩ = 1, the vector c + l must be in 𝒞. Columns with ⟨c,v⟩ = 0 are fixed automatically. This is equivalent to b(Tu) = b(u) for all 1024 u, since both say T preserves the weight function.

Recovering the coordinate permutation.

1. For each column c_i of B, compute c_i + ⟨c_i,v⟩·l.
2. Look it up in the column list to get an index π(i).
3. π is a permutation of the 37 coordinates because it is a bijection on the set 𝒞 of distinct columns.
4. Then B·P_π = T·B in matrix form.
