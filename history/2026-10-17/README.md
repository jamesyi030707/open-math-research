# 从精确模型到尚未认证的不可行状态

[精选手记](../../notes/codes-covering.md) · [前一日模型](../2026-10-16/README.md)

## 结果

- 当前 Grassl 表仍列二元[64,11]最小距离26–27。
- 固定扩展 BCH 母码 E 已准确识别为一个(6,3)-bent函数码 C_F。适用的已有结果只给覆盖半径≤27；不能据此排除距离27的奇余类。
- 512条双边约束完整保留同一个64位函数。信息集规范化给出54个自由二元坐标，奇偶约束另外保留。
- Claude 提供的 HiGHS 日志报告59.6进程CPU秒后 infeasible。没有不可行证书，结论仍未决。

## 实际核查

[模型检查器](independent/model_check.py)核对512代表及补字正好覆盖E；四个样例核对Walsh接口与直接距离。[商空间检查器](independent/quotient_check.py)给出10位信息集的RREF证书。[LP审查器](independent/audit_lp.py)逐条核对导出的1024个标量界、奇偶等式、54个二元变量与整数辅助变量。没有重跑求解器，也没有证明不可行。

[文献映射程序](independent/literature_mapping.py)核查 BCH 根集合、迹函数空间和原码空间的相等性。独立检查是有限代数计算，不是新的全局编码界。
