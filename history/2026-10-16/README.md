# 2026-10-16 · 从分布约束到共同坐标

[精编手记](../../notes/codes-coset.md) · [真实交流摘录](EXCHANGES.md) · [勘误](ERRATA.md) · [一手来源](SOURCES.md)

## 结果与边界

已知扩展 BCH [64,10,28] 母码的奇余类必要重量分布恰有 25 种。独立整数计算重建全部 1,024 个码字，检查完整 MacWilliams 条件，另以两个端点及整数斜率证书复核。

随后明确验证 RM(1,6) 的 128 个码字包含于母码，验证三条显式互补生成元及其七个非零组合均为二次 bent 函数。由此得到同一个 64 位奇重量函数满足 512 条双边 Walsh 约束的精确模型。只验证模型接口，没有求解其可行性。

两轮真实讨论的可见最终回复保留为 round1_final.txt、round2_final.txt。原始数学产物以 claude_ 前缀保留，独立实现置于 independent/。所有个人资料及页面操作元素均未收录。

## 复现

Python 3.10+，仅标准库。在临时副本运行，因为脚本会重写旁边的结果文件：

```sh
python independent/verify.py
python independent/certificate.py
python independent/verify_rm_model.py
```

verify.py 重建有限域、生成多项式、重量分布、对偶分布和全部 25 个整数点；certificate.py 检查端点及整斜率；verify_rm_model.py 检查 RM 包含关系、两套互补基、七个 bent 二次函数，并用三个固定测试向量核对 Walsh 距离公式。最后这三个向量是接口核查，不是余类搜索。

## 下一步及停止条件

目标是这个已知母码的覆盖距离/奇余类问题，服务于短二元纠错码构造。当前表中 [64,11] 的界仍为 26–27。下一次先查现有覆盖半径或 bent-space 文献，避免重复已知分类；若没有直接定论，再把已写明的共同变量模型编码为可验证的整数或 SAT 问题。

首次求解预算不超过 120 CPU 秒。找到候选时枚举母码 1,024 个距离并公布向量；得到不可行时需要可独立检查的证书；超时或没有证明产物则记录未决，不扩大搜索以凑结果。必要分布可行不作为构造，未找到不作为不存在。
