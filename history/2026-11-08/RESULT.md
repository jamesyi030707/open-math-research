# A column-incidence cut beyond q >= 16

## Result

For the archived residual B and the left-projection-kernel-one branch, every actual target lift satisfies

**2a + d - b - 2 >= 0.**

Here (a,b,c,d,e,f,g) are the integer coordinates from 2026-11-04, and q=4d. In the original seven counts this is

**p + 5q - 2y10 - y14 + 3z8 + 2z12 + z16 - 60 >= 0.**

The two expressions differ by a factor of 32. This is a necessary condition for actual linear realizability, not a sufficient condition.

It is not implied by the previous 1,075 formal constraints together with q>=16. The exact formal point

- Integer coordinates: (6,19,10,4,-31,-33,66).
- Seven counts: (26,16,140,0,0,4,66).

passes all 11 count bounds and all 1,064 nonnegative-integral split MacWilliams coefficients, and has q=16. Its new cut slack is -5. Thus every message labelling of this point fails in this fixed residual/kernel-one branch.

This does **not** exclude the whole branch or any entire remaining q value. Explicit formal points satisfying both the old model and the new cut are provided for each q=16,20,24,28.

## New incidence information

Write each column of B as a ten-bit message functional. The original matrix has 37 distinct nonzero column labels. Precisely five satisfy h dot v=0:

{1,4,7,13,15}.

These occur at zero-based residual positions 32 through 36, and every one also vanishes on S. The other 32 residual columns have h dot v=1.

Because hA=0, every A column annihilates h. Consequently, if an A column equals a B column, it equals one of those five and must vanish on S.

Let Z be the number of globally zero A columns and M the number of ordered A/B column coincidences. Since the B columns are distinct, M counts A positions without multiplicity from the right block. Since B has no zero column, those positions are disjoint from the Z zero positions. Both groups lie among the d-4 positions vanishing on S. Thus

Z+M <= d-4.

For D generated by [A|B], the split dual coefficient T(1,0) counts precisely zero A columns. T(1,1) counts precisely matching A/B column pairs: a binary vector with one coordinate in each block lies in D-perp exactly when those two column functionals are equal. No stronger dual-distance assumption is needed.

The archived affine table gives

Z=T(1,0)=a-6, and M=T(1,1)=b-3a+4.

Substitution gives (a-6)+(b-3a+4)<=d-4, proving the stated cut. The slack 2a+d-b-2 has a concrete meaning: it is the number of A positions vanishing on S whose nonzero column label is not a B column.

The old coefficient inequalities already imply a>=6 and b>=3a-4. Together with the new inequality these yield a<=d+2, hence d>=4. Thus the new cut subsumes the November 7 q>=16 lower bound when joined with these two old nonnegativity conditions. It is a strict strengthening relative to the old model plus that bound.

At q=16, d=4, every realizable lift must have a=6 and b=14, equivalently T(1,0)=T(1,1)=0. The rejected point instead has T(1,0)=0, T(1,1)=5 while no A coordinate may vanish on S. The contradiction is independent of all message-labelling choices.
