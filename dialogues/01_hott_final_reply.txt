3. LEM 与证书型 Σ

先明确：LPO 取证书型 LPO_Σ。它与截断型等价，由最小见证抽取（Lemma M）得到：若每个 P n 是命题且可判定，则 ∥Σ n, P n∥ → Σ n, P n。

步骤：令 Q n := P n × (∀j<n, ¬P j)。Σ n, Q n 是命题，因为两个最小见证相等。对 j ≤ n 做有界搜索，得到 Σ P → Σ Q。对命题 Σ Q 做截断递归，再忘掉最小性。

无 judge 的 c₂ 在 LEM 下成立，且不需要选择原则：

P_C n 是命题（F1）。
LEM 本身是函数，n ↦ LEM(P_C n) 就给出对 n 一致的 judge。
对命题 ∥Σ n, P_C n∥ 用 LEM：yes 分支用 Lemma M 取回非截断的 Σ，no 分支给出 ∀n ¬P_C n。
需要在 Agda 里核对的只有：该命题所在宇宙层级，以及 Σ Q 的命题性。
这是我的推导，不是库里现成的定理。
4. 编码 E 的逐项检验

约定： P_C(n) := isOfHLevel (n+2) C；K_n := K(ℤ, n+1)。

K_n 的事实： isOfHLevel (n+3) K_n，¬isOfHLevel (n+2) K_n。

n=0：S¹，是群胚，不是集合。
n=1：K(ℤ,2)，h-level 4，不是 3。
n=2：K(ℤ,3)，h-level 5，不是 4。
这与仓库 C-82 的"3+b 落定、2+b 不落定"形状一致，但我没读源码，库接线待做。

构造： β n := α 0 ∨ … ∨ α n，Y n := if β n then ⊤ else K_n。

引理 E：P_{C_α}(m) ↔ (β m ≡ true)。

上界（⇐）不需要构造"尾部变 ⊤"的等价，也不需要先抽取最小值：

设 β m = true。
若 β n = true，则 Y n = ⊤。
若 β n = false，由 β 单调知 n < m，故 Y n = K_n 的 h-level 是 n+3 ≤ m+2。
对每个因子用 isOfHLevelΠ 即得 isOfHLevel (m+2) C_α。

下界（⇒）用 retract，不是"收缩核"：

设 β m = false，则 Y m = K_m。
截面 s x：在位置 m 放 x（先沿 β m = false 运输），其余位置放基点（K_n 的 embase，⊤ 的 tt）。
退缩映射：取位置 m 的投影。
retract 保持 h-level，所以若 isOfHLevel (m+2) C_α，则 isOfHLevel (m+2) K_m，矛盾。

最小值抽取放在哪： 用到它的只有由 Φ 的输出回到 LPO 时，即从 β m = true 得到 Σ i ≤ m, α i = true，对 m 归纳即可。

5. 单轨迹对抗证明

把算法限定为"确定性、每次运行有限次读取 oracle"。唯一用到的性质是局部性：若 β 与 α 在 α 上那次停机运行读过的所有位置一致，则在 β 上的运行完全相同，包括读取轨迹和输出。

证明：

在 α⁰（全假）上运行，得到有限读取集 S，S 可以为空，也可以含重复和自适应读取。
若输出是 inl n，它已经在 α⁰ 上错了，n 是否在 S 里无关紧要。
若输出是 inr，令 N := max S（S 为空时取 −1），α¹ i := (i > N)。α¹ 与 α⁰ 在 S 上一致，局部性给出同一输出 inr，但 α¹(N+1) 为真。∎

关键点：

只用到在 α⁰ 上停机，不需要统一时间界，也不需要良基二叉树。
对抗序列都是单调的，与 judge 的单调性（F2）相容。

覆盖的模型： 带查询指令的图灵机和 RAM、判定树、Delay 余代数形式的 oracle 程序，以及任何满足局部性的确定性模型。

不覆盖：

随机算法（需另做概率论证）。
白盒读取 judge 的代码或证明（这恰恰是目标 (b)）。
额外 oracle，例如停机 oracle。
不停机的运行（目标 (a) 允许在 α⁰ 上永不停）。
